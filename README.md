# Maclike Dock

A fluid dock for GNOME Shell with magnification, dynamic blur, and folder stacks.

## Features
- Smooth icon magnification
- Apple-style Liquid Glass blur engine
- Folder stacks (fan and grid presentations)
- Live indicators and Trash Bin
- Works on GNOME 45+
